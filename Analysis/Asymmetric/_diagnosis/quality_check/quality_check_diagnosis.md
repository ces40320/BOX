## 5. Recommendations

1. **IK archive (done in pipeline code):** `run_ik` now sets a unique tool name and `results_directory` to the segment `IK/` folder so future runs keep `*_ik_marker_errors.sto`.
2. **L5–S1 / pelvis reserves:** If ID ratios ≫ 1 dominate SO failures, consider raising `torque_L5_S1_*` / residual `optimal_force` in `add_reserve_actuators.py` and regenerating models — or accept that SO will lean on large controls for those DOFs.
3. **Scaling:** Subjects with mean body RMSE ≳ 4 cm (often head/shoulder) should be re-checked in AddBiomech before trusting distal arm SO/JR.
4. **Cross with SO trouble:** Compare high `worst_ratio` / bad IK rows to `pipeline_trouble.json` when prioritizing retries.
