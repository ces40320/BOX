# 흉곽 타원체 기하 피팅 (`chest_wrap_geometry_fitting`) SUB1–SUB8 결과 리포트

- **작성일**: 2026-11-28
- **대상**: Asymmetric 프로토콜 전체 피험자 SUB1–SUB8 (`MeasuredEHF`, 전체 IK trial 1,015개)
- **방법**: 근육 경로(`GeometryPath`)는 유지하고 `torso`에 부착된 좌·우 흉곽 타원체(`Chest_r`, `Chest_l`)의 반지름·위치·회전을 좌우 대칭으로 피험자당 1회 미세 조정 (1단계 거친 격자 탐색 → 2단계 9차원 Nelder-Mead 미세 조정)
- **평가**: 피험자별 원본 모델(`SUB*_Scaled.osim`) 대비 피팅 모델(`SUB*_ChestFix.osim`)의 전체 IK trial에 대해 근육 길이 점프 횟수, 정상 프레임 기준 길이 RMSE, L5–S1 모멘트암 RMSE, 2차 미분 매끄러움 비교

## 2. 핵심 관찰 사항

1. **전원 길이 점프 0건 달성**
   - SUB1–SUB8 총 1,015개 IK trial 전체에서 원본 모델의 길이 점프 3,867건이 피팅 후 **0건**으로 완전히 제거되었습니다.
2. **원본 유지 그룹 (SUB3, SUB4, SUB6)**
   - 원본 모델에서 이미 길이 점프가 0건이었으며, 최적화 결과 원본 타원체가 그대로 유지되어 모든 평가 항목(길이·모멘트암·점프)을 100% 통과했습니다.
3. **반지름 소폭 축소 그룹 (SUB2, SUB5, SUB7, SUB8)**
   - 중심 위치와 회전은 그대로 두고 반지름만 2.5–5% 축소해 점프를 완전히 제거했습니다.
   - 정상 프레임 기준 길이 RMSE 중앙값 **1.92–2.28 mm**, 모멘트암 RMSE 중앙값 **0.62–0.84 mm**로 피험자 간 일관성이 높습니다.
4. **SUB1 (추가 검토 대상)**
   - 기본 격자 탐색(`radii_scale >= 0.95`)에서 반지름 축소만으로 점프 0건 지점이 나오지 않아 뒤쪽 이동(`-2.79 mm`)과 미세 회전(`< 1°`)이 포함된 해로 수렴했습니다.
   - 길이 점프는 533건 → 0건으로 완전히 제거되었으나, 길이 RMSE(중앙값 4.26 mm, p95 47.84 mm)가 다른 피험자보다 큽니다. 더 작은 반지름 격자(예: `0.90` 이하)를 포함한 재피팅으로 길이 오차를 줄일 수 있는지 확인이 필요합니다.
