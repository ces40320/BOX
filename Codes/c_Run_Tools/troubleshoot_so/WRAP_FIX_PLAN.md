# Chest 감싸기(wrap) 실패 수정 계획 — LoadShare 척추 모델

> 범위: **계획 문서만**. 분석/수정 코드는 아직 없음. 결정 사항: 기존 우회책(FunctionBasedPath `wrap_fbp`, PR #4 PolynomialPathFitter)은 폐기하고 **Chest 감싸기를 고쳐 GeometryPath를 유지**한다.

## 0. 배경과 현재 상태

- 증상: 흉추 최장근 LTpT T3/T4 좌·우 경로(lumbar3 → lumbar1 → torso, torso의 `Chest_l`/`Chest_r` 타원체를 감쌈)의 근육 길이가 일부 프레임에서 0.43 ↔ 0.76 m로 튐.
- 모델 결합(coupler): L4/L5 ~ T12/L1 회전과 복부(Abs) 좌표가 **L5-S1 3개 좌표의 선형 함수**다. 따라서 경로 형상은 사실상 L5-S1 굴곡·측굴·회전 3개 자유도만으로 결정된다. 진단 축으로 쓰기에 좋다.
- 템플릿(`OpenSim/_Main_/c_AddBio_Continous/SUB1/APP2/SUB1_Scaled_AddBiomech_APP2.osim`)의 Chest 타원체:

| 항목 | Chest_r | Chest_l |
|---|---|---|
| 부착 body | torso | torso |
| 반지름 (x, y, z) [m] | 0.0928, 0.2002, 0.1435 | 동일 |
| 위치 [m] | (0, 0.2468, +0.0107) | (0, 0.2468, −0.0107) |
| 회전 xyz_body [rad] | (0, −0.4, 0.2) | (0, +0.4, 0.2) |
| 활성 사분면(quadrant) | `z` | `-z` |

- Chest를 참조하는 근육은 **37개**: LTpT_T1–T5 좌·우(10개), LD_T7–T12, LD_L1–L5, LD_R11/R12, LD_Il 좌·우(27개, LD_R12_r 없음). 진단은 4개가 아니라 37개 전부를 대상으로 한다.
- 이전 작업(손대지 않음): `wrap_fbp/` (튐 검출 `detect_length_jumps`, Chest 보조 경로 `ChestPatch` 격자 탐색, 복구 단계), `wrap_detect_lib.py`, `wrap_gapfill/`, `RUN_fix_muscle_path_wrap_fail.py`. 결과는 `Analysis/Asymmetric/_diagnosis/wrap_fbp/SUB8/` (81개 trial, 대체 경로 길이 RMSE 중앙값 약 0.12 cm). 폐기 이유: 고부하 구간(주기 30–45%)에서 외삽, 분절 반력 손실, trial마다 다른 모델.
- 이번 계획에서 재사용할 것: 튐 검출 기준(`detect_length_jumps`), 타원체 국소 좌표 변환 및 내부/현(chord) 관통 판정(`_to_wrap_local`, `_inside_ellipsoid`, `_chord_hits_ellipsoid`), IK 행 적용(`_apply_ik_row`). **복사하지 않고** 새 공용 모듈에서 import하거나 다시 구현한다. 기존 파일은 수정하지 않는다.

## 2. 단계별 작업

### 1단계 — 진단 (SUB8 먼저)

목표는 **어느 시점에 어느 근육이 어느 방향으로** 감싸기를 벗어나는지 프레임 단위로 파악하는 것이다.

프레임별, 근육별 기록 항목(`chest_diag_<SUB>_<trial>.csv`, 행 = 프레임 × 근육):
- 시간, 동작 주기 %, AB·BC·CA 분절 구분, 조건(무게/bpm), 손 힘(MeasuredEHF / HeavyHand) 크기
- L5-S1 3개 좌표, 그리고 결합으로 결정되는 척추 좌표(L4/L5 ~ T12/L1, Abs) 값. 결합식 잔차도 검증한다.
- 근육 길이와 프레임 간 Δ길이, 튐 플래그(기존 검출 기준과 동일)
- 감싸기 결과: 감싸기 활성 여부, 두 접점(tangent point)의 지면 좌표 및 타원체 좌표, 감싸기 호 길이. 데이터는 `PathWrap`의 감싸기 결과와 현재 경로점 목록에서 얻는다(`getCurrentPath`).
- 경로점(원점, lumbar 경유점, torso 삽입점)의 **타원체 국소 좌표**, 타원체 표면까지의 부호 있는 거리(정규화 거리 √Σ(x/r)² − 1 및 근사 거리 [m]), 활성 사분면 쪽에 있는지 여부(국소 z의 부호)
- 경로점 사이 현이 타원체를 관통하는지 여부(감싸기가 꺼져 있는데 관통하면 "관통 실패")
- 모멘트암: L5-S1 3개 좌표에 대해 **결합을 포함한 전체 미분**으로 계산한다. 수치 미분이 결합 좌표까지 함께 움직이도록 한다.

실패 유형 분류(`failure_type`):
1. **관통**: 감싸기가 비활성인데 경로가 타원체를 통과함
2. **반대쪽 감싸기**: 접점이 활성 사분면 반대편에 있음
3. **감싸기 풀림 / 재감김**: 감싸기 활성 여부가 바뀌면서 길이가 불연속함
4. **접점 점프**: 감싸기는 유지되지만 접점이 타원체 위에서 크게 이동함(측지선 해가 다른 쪽으로 넘어감)
5. **끝점이 타원체 내부**: 원점 또는 삽입점이 타원체 안에 들어감(타원체 크기·위치 문제)

산출물:
- `chest_diag_summary_<SUB>.json`: 근육 × 유형별 프레임 수, 최초 발생 시점, 그때의 L5-S1 좌표 범위
- 그림:
  - 근육별 길이-시간 곡선에 실패 유형을 색으로 표시
  - L5-S1 굴곡×측굴 평면 산점도(정상/실패, 실패 경계)
  - 타원체 국소 좌표계에서 본 접점 궤적(3개 투영면)
  - 주기 % 히트맵(근육 × 주기, 실패 비율)
- 결정 근거 표: 실패가 "좌표 공간의 특정 영역"에 몰려 있는지, 특정 근육군(LTpT 상부 / LD)에 한정되는지 정리

### 2단계 — 평가 틀 고정 (A·B 공통)

- 기준값은 **원본 모델의 정상 프레임**(튐이 없고 감싸기가 정상인 프레임)에서 구한 근육 길이와 모멘트암이다.
- 평가 대상은 SUB8의 전체 trial × 전체 프레임 × 37개 근육이다. 모멘트암 비교는 근육마다 원본 정상 프레임 위에서 하고, 실패 프레임에서는 연속성(2차 미분 크기)만 본다.
- `RUN_chest_wrap_evaluate.py`가 성공 기준(4절) 판정 JSON(`eval_<SUB>_<variant>.json`)을 출력한다.

### 3단계 — 방안 A: Chest 타원체 조정

- **변수**: 좌·우 대칭으로 반지름 3개, 위치 3개(좌우 z는 부호만 반대), 회전 3개, 사분면(`z` / `-z` / `all` 후보). 좌·우를 따로 조정하는 경우는 진단 결과 비대칭이 확인될 때만 허용한다.
- **제약(해부학적 타당성)**:
  - 반지름과 위치는 원본 대비 ±30% 이내, 회전은 ±0.3 rad 이내
  - 흉곽 크기와의 일치: 원본 모델 흉곽 폭·깊이(torso 표지점 및 스케일 계수 기준)를 넘지 않을 것
  - 37개 근육 원점·삽입점이 모두 타원체 밖에 있을 것(여유 ≥ 5 mm)
  - 척추체·견갑 경로점과 겹치지 않을 것
- **목적함수**:
  - 전체 trial 전체 프레임에서 튐이 없을 것(하드 제약 또는 큰 페널티)
  - 정상 프레임에서 원본과의 길이·모멘트암 RMSE가 작을 것
  - 길이 곡선이 매끄러울 것(2차 미분 페널티)
  - 원본으로부터의 변경량이 작을 것(정규화)
- **탐색 방법**: 1단계에서 실패가 일어난 좌표 영역의 프레임과, 그와 균형을 맞추기 위한 정상 프레임 일부를 표본으로 뽑는다. 이 표본에 대해 격자 탐색으로 거친 탐색을 한 뒤 Nelder-Mead 또는 CMA-ES로 다듬는다. 마지막에 전체 프레임으로 검증한다. 기존 `ChestPatch`가 "크기 비율과 후방 이동"의 2개 변수만 썼던 한계를 넘는 것이 목적이다.
- **산출물**:
  - `A/chest_params_<SUB>.json`: 파라미터와 제약 여유
  - 피험자 단위 `<SUB>_..._ChestFix.osim` 1개. trial별 모델은 만들지 않는다.
  - 최적화 이력 그림, 수정 전후 길이 곡선과 접점 궤적 비교 그림

### 4단계 — 방안 B: 경유점 / 조건부·이동 경로점으로 교체

- **대상 근육**: 1단계에서 실패가 확인된 근육만 바꾼다(최소 LTpT_T3/T4 좌·우, 결과에 따라 T1–T5 및 일부 LD). 실패가 없는 근육은 감싸기를 유지한다. LTpT 계열 안에서 일관성이 필요하면 계열 전체를 바꾸는 방안도 비교한다.
- **경로점 수와 부착 body**: torso에 경유점 1–2개를 둔다. 필요하면 lumbar1 또는 lumbar3에 1개를 추가한다. 결합 때문에 lumbar 분절도 L5-S1 좌표에 따라 움직이므로, 부착 body 선택이 모멘트암 형태를 결정한다. 후보 조합(torso만 / torso + lumbar1)을 비교한다.
- **위치 결정**: 원본 모델 정상 프레임의 감싸기 경로(접점과 호 위의 점)를 각 body 좌표계로 옮긴 뒤 최소제곱으로 고정점을 맞춘다. 고정점으로 오차가 남으면 이동 경로점(MovingPathPoint, L5-S1 굴곡 등의 1차원 스플라인)을 쓰고, 그다음 조건부 경로점(ConditionalPathPoint)을 쓴다. 조건부 경로점은 점이 켜지고 꺼질 때 길이 불연속이 생기므로 마지막 수단으로만 쓴다.
- **모멘트암 연속성**: 이동 경로점의 스플라인을 매끄럽게 하고(2차 미분 페널티), 전체 L5-S1 범위에서 모멘트암에 불연속이 없는지 확인한다. 정상 프레임 범위 밖에서는 외삽하지 않도록 기울기를 제한하고 범위를 잘라 둔다.
- **산출물**: `B/via_points_<SUB>.json`(근육별 점, 부착 body, 함수 계수), 피험자 단위 `<SUB>_..._ChestVia.osim`, 맞춤 오차 그림

### 5단계 — SO/JR 비교 (SUB8)

- 원본(정상 trial), A, B 모델로 정적 최적화(SO)와 관절 반력(JR)을 다시 계산한다. 비교 대상은 L5-S1 IVD 반력 fx/fy/fz, 근육 힘(LTpT, LD, 기타 신전근), 예비 토크(reserve)다.
- 조건(7/15 kg × 10/16 bpm)별, AB·BC·CA 분절별, 주기 %별 평균 곡선을 그린다. 특히 고부하 구간인 주기 30–45%를 집중해서 본다.
- 기존 `tmp_wrap_vs_normal_stats` 형식을 참고해 `compare/so_jr_<SUB>.json`과 그림을 만든다.
- 공식 결과 폴더(`SO_<app>`, `JR_<app>`)의 기존 파일은 덮어쓰지 않고, 각 폴더 아래 `troubleshoot_so/chest_wrap_<A|B>/`에 후보 결과를 저장한다.

### 5-2단계 — 외적 타당도 검증 (기존 정상 trial 대상, 피험자 공통)

방안 A(타원체 조정)로 오류 trial을 해결한 뒤, **기존에도 정적 최적화가 정상 통과하던 trial들**에 부작용이 생기지 않았는지 확인한다. 이 검증은 SUB8뿐 아니라 6단계에서 방안 A를 적용하는 **모든 피험자**에 동일하게 수행한다.

1. **IK 근육 경로 진단 (정상 trial 전체):**
   - 기존 정상 trial 전체(오류 복구 대상 외 나머지 IK 전체)에 대해 `<SUB>_ChestFix.osim`으로 근육 경로 진단을 수행한다.
   - **판정 기준:** 주요 진단 항목인 길이 튐(`length_jump`)과 관통(`pierce`)의 발생 빈도가 기존 모델보다 증가하지 않아야 하며, 기타 항목(`endpoint_inside`, `unwrap_rewrap`, `tangent_jump`, `wrong_side`)도 급증하지 않아야 한다.
   - **보관 위치:** `Analysis/<protocol>/_diagnosis/chest_wrap/<SUB>/diag_A_normal/`
2. **SO·JR 관절 반력 비교 (정상 trial 샘플):**
   - 기존 정상 trial 중 조건별 대표 샘플(예: 조건당 1건 이상)을 `<SUB>_ChestFix.osim`으로 SO·JR 재계산하여, 기존 공식 `JR_MeasuredEHF`의 L5–S1 관절 반력(fx/fy/fz)과 비교한다.
   - **판정 기준:** L5–S1 관절 반력이 기존 공식 결과와 유사해야 하며(평균·고부하 구간 차이 ≤ 5% 목표), 큰 편차가 없어야 한다.
   - **보관 위치:** 개별 SO/JR은 `troubleshoot_so/chest_wrap_A/`, 비교 요약은 `Analysis/<protocol>/_diagnosis/chest_wrap/<SUB>/compare/so_jr_normal_sample_<SUB>.json`

### 6단계 — 선택 및 다른 피험자로 일반화

- A와 B 중 하나를 선택한다(5절). 그 뒤 다른 피험자(SUB1 등 전체)에 **같은 절차**를 적용한다. 방안 A는 타원체 파라미터를 피험자 스케일로 정규화해 이식하고, 방안 B는 경유점을 body 좌표계에서 스케일 계수로 이식한다. 이식한 다음 피험자별로 다시 검증(오류 trial 해소 확인 + **5-2단계 외적 타당도 검증**)하고, 실패하는 경우에만 재최적화한다.
- 산출물은 `compare/cross_subject_summary.json`이다(피험자별 튐 수, 오차, 파라미터 편차, 정상 trial 외적 타당도 결과).

## 4. 성공 기준

| 기준 | 방안 A | 방안 B |
|---|---|---|
| 튐 제거 | SUB8 전체 trial·프레임·37개 근육에서 튐 0건, 실패 유형 1–5 모두 0건 | 바뀐 근육에서 튐 0건, 감싸기를 유지한 근육도 0건 |

| 매끄러움 | 길이 2차 미분이 정상 프레임 분포의 99백분위 이내 | 동일 |

| SO/JR | 원본 정상 trial 대비 L5-S1 반력 평균 차이 ≤ 5%, 예비 토크 증가 없음, 주기 30–45% 반력 손실 없음 | 동일 |

수치 임계값은 1단계 결과(정상 프레임의 자연 변동)를 보고 확정한다.

## 5. A·B 비교 및 선택 방법

1. 두 방안 모두 성공 기준의 하드 항목(튐 0건, 피험자 단위 모델, 해부학적 타당성)을 통과해야 한다.
2. 둘 다 통과하면 다음 순서로 고른다: (a) 모델 변경 범위가 작은 쪽. A는 타원체 2개만 바꾸고, B는 근육 경로를 바꾼다. (b) 정상 프레임 모멘트암 오차가 작은 쪽. (c) SO/JR이 원본 정상 trial에 가까운 쪽. (d) 다른 피험자로 이식하기 쉬운 쪽.
3. 기본 선호는 **A**다. 감싸기를 유지하므로 LD 등 다른 근육의 거동도 보존된다. A가 LTpT와 LD를 동시에 만족시키지 못하면 **A + 국소 B**로 간다. 즉 타원체는 LD에 맞추고 LTpT 상부만 경유점으로 바꾼다.
4. 결정 내용은 `compare/decision_<SUB>.json`과 이 문서 부록에 기록한다.

## 6. 위험 요소와 대안

- **타원체 하나로 모든 근육을 만족시키지 못함**(LTpT와 LD가 서로 다른 형상을 요구) → 대안: 근육군별로 타원체를 분리(Chest_LTpT_l/r 추가)하거나 A + 국소 B를 쓴다.
- **사분면을 바꾸면 다른 근육이 반대쪽으로 감김** → 37개 근육 전체를 진단 범위에 넣어 확인한다.
- **OpenSim 감싸기 알고리즘 자체의 수치 불안정**(타원체 측지선 해가 두 개인 경우) → 대안: 형상이 비슷한 원통(WrapCylinder) 또는 구로 바꾸는 것을 검토하거나 B로 전환한다.
- **조건부 경로점의 불연속** → 이동 경로점을 우선 쓴다.
- **결합된 좌표 때문에 생기는 모멘트암 정의 혼동** → 결합을 포함한 전체 미분으로 통일한다.
- **로컬 실행이 오래 걸림**(81개 trial × 최적화) → 표본 프레임으로 최적화하고 전체 프레임은 검증에만 쓴다.
- **입력 파일이 저장소에 없음** → 3절의 공유 목록을 먼저 요청한다.
- **해부학적 기준 데이터가 부족함** → 스케일된 torso 표지점과 문헌의 흉곽 크기를 사용하고, 필요하면 사용자가 확인한다.
