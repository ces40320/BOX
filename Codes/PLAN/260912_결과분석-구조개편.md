## 2. 처리·정리한 내용

### 2.1 분석 모듈 스코프 (사용자 요청 0–5)

| # | 내용 | 상태(대화 기준) |
|---|------|-----------------|
| 0 | MeasuredEHF **5 N** onset–offset 기준 자르기, 101점 리샘플, **시간 스케일 비** CSV | 구현·사용 |
| 1 | EHF: Measured / HeavyHand(마커 rect) / pre / post, 손별 3축+resultant, RMSE | 구현·피규어 |
| 2 | L5S1: 힘 3축+resultant, 모멘트 3축 (학계 용어로 정렬) | 구현·피규어 |
| 3 | Residual: x,y,z + Hicks형 5% 임계 **데이터 저장** (supplementary 후보) | **CSV 저장됨** (`Residual/MeasuredEHF/_metrics/Hicks_*.csv`); 본문 주력 아님 |

### 2.2 디렉터리 규칙

- `Analysis/Asymmetric/EHF|L5S1|Residual/{app}/{축}/…` 라벨된 시계열.
- `_figures/`: SUB별 + 조건 하위 + **SUBALL**(4 app 모두 trouble 없이 통과한 피험자만; `pipeline_progress.xlsx` 기준). SUBALL에 포함 피험자·조건당 n을 짧은 엑셀로 기록.
- RiCTO: `Analysis/RiCTO` → **`Analysis/Asymmetric/RiCTO/`**  
  - `Summary/` (SUB#_RiCTO_report.xlsx, SUB 하위 폴더 없음)  
  - `TimeSeries/` (SUB 하위 허용)  
  - `_validation/`, `_notes/`  
- 최적화 직후 Summary 자동 갱신; 중복 `Results/`·레거시 `_synthetic` **제거** 방향.
- 리포트 탭: GT 5 N 시점 오차·by_segment 통합, SD 병기, error_log 행은 리포트에서 **삭제**, qc_warning에 시점 오차 과다 포함.

### 2.3 접촉 창 정렬 (09-14)

앱마다 grip 정의가 다름을 인정하고:

- MeasuredEHF: **5 N** 창  
- HeavyHand: **박스 마커** 궤적  
- pre/post: **RiCTO 최적화** 창  

비교 시: GT 5 N 기준으로 밖이면 자르고, 안쪽 미접촉은 0으로 맞춘 뒤 리샘플.  
RMSE는 101점 **쿼터 구간**별 분석 + `_validation` 힘 검증 반영.

### 2.4 피규어·RMSE 패널 (09-15)

- EHF / L5S1에 **체중 정규화 RMSE(+SD)** 패널, SUBALL, **AB·BC·CA** 모두.
- L5S1 파일명 규칙(축·모멘트 용어) 점검·재명명 요청.
