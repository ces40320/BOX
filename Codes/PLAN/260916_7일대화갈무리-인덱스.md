1. **센서리스 RiCTO 원칙**을 다시 세우고 → Dropbox 레거시와 후배 `ricto_core`를 비판적으로 비교 → `Codes/c_Run_Tools/optimization/`에 재구현.
2. **Asymmetric 전 피험자 OpenSim 배치**를 돌리기 위해 진행 시트·멀티프로세싱·SO 고착·재시도 체계를 만듦.
3. **결과 분석 파이프라인**을 노트북에서 `.py`로 재구성하고 `Analysis/Asymmetric/` 아래 EHF·L5S1·Residual·RiCTO로 정리.
4. **마커 기반 접촉**이 휴리스틱·결측이 많음을 실데이터로 확인 → 보고서용 한계 노트 작성.
5. **통계(LMM)·시점 Bland–Altman·솔버 벤치마크**로 논문/발표 쪽 산출물 생성.
