## 2. 처리·정리한 내용

### 2.1 문제 성격 → 솔버 선정 전제

- residual 시계열 피팅, 결정변수 4개 동시, weight로 조각적 매끄러움, 물리 bounds.

### 2.2 후보 4종

| 약어 | 역할 |
|------|------|
| nm (Nelder–Mead) | 도함수 불필요; bounds 약함 |
| **least_squares** | **기본**; bounds·nfev |
| de | 전역; 비용↑ |
| grid_local | 견고성 보조 |

### 2.3 산출물 규칙 (확정)

| 허용 | 비허용 |
|------|--------|
| `solver_compare_all.csv`, `solver_compare_summary_by_solver.csv` | `_synthetic/` 폴더 |
| 발표 md의 실데이터 표 | `solver_compare_synthetic.csv`를 Analysis에 보관 |
| `validate_ricto --solvers` **콘솔** 유닛 테스트 | 합성 CSV를 피험자 벤치처럼 인용 |
