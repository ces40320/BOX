# Prior research materials

문헌·이론 노트와 참고 링크를 둔다. PDF 원문은 용량·저작권상 이 폴더에 대량 커밋하지 말고, 요약 MD + DOI/URL만 유지하는 것을 권장한다.

## Contents

| file | purpose |
|------|---------|
| `LMM_LITERATURE_NOTES.md` | LMM 개념 + 리프팅/생체역학 적용 사례 요약 |
| (optional) `pdfs/` | 로컬 참고용 — `.gitignore` 후보 |

## How to add a paper

1. 한 줄 인용 (APA 또는 저널 스타일) + DOI  
2. 우리 설계와의 대응: 고정효과 / 랜덤효과 / 결과변수  
3. 코드에 옮길 때 주의점 (정규화, 결측, 반복측정 단위)
